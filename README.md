# EventCraft 

Hi! Welcome to my project **EventCraft**.

EventCraft is an event management website where users can explore different types of events and send enquiries for their events.

I created this project to practice my web development skills and learn how frontend and backend work together.

# About the Project

This website is made for managing event enquiries. Customers can register, log in and submit their event details. Admin can log in and manage the enquiries through the dashboard.

# Features

- Home page with event details
- Different event categories
- Customer registration and login
- Customer dashboard
- Event enquiry form
- Admin login
- Admin dashboard
- Add, view, update and delete enquiries

# Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt

# How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
npm install
```

5. Create a `.env` file and add your MongoDB URL and other required details using `.env.example`.
6. Start the server:

```bash
npm run dev
```

7. Open the frontend using Live Server.
